SinceArc

A Windows desktop client for ACP agents that keeps the process visible: thinking and tool calls live in a trace swimlane, not buried in the chat stream.

把 agent 的思考与工具调用从对话里拆出来，做成一条能回看的泳道。

Why another client

Process apart from prose

Replies stay in the chat; thinking, tool calls and permission prompts go into a trace panel. The two cross-link by anchor, so you can always ask “why did it do that” and get an answer.

Local first

Sessions, traces and settings live in %APPDATA%\com.sincearc.app. Nothing is uploaded, and the client works fully without any account.

It never disposes of your data

Deleting a session or a file requires explicit authorization. There is no “helpful” automatic cleanup — storage is counted and reported, never acted on.

What it is not

  • Windows x64 only. No macOS, Linux or ARM64 builds, and no unverified artifacts.
  • Unsigned. SmartScreen warns once on first run; choose “More info → Run anyway”.
  • No auto-update yet. Upgrading means downloading a new package.
  • Trace paging is limited. The panel loads 50 turns at a time; older traces need pagination.

Install

  1. Download SinceArc-<version>-win-x64.zip (portable) or the setup .exe.
  2. Extract somewhere real — not inside the zip — then run SinceArc.exe.
  3. Needs WebView2 Runtime: shipped with Windows 11 and recent Windows 10.
