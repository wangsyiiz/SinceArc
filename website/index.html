Why another client

Process apart from prose

Replies stay in the chat; thinking, tool calls and permission prompts go into a trace panel. The two cross-link by anchor, so "why did it do that" always has an answer.

Local first

Sessions, traces and settings live in %APPDATA%\com.sincearc.app. Nothing is uploaded, and the client works fully without an account.

It never disposes of your data

Deleting a session or a file requires explicit authorization. Storage is counted and reported, never acted on.

What it is not

  • Windows x64 only. No macOS, Linux or ARM64 builds, and no unverified artifacts.
  • Unsigned. SmartScreen warns once on first run; choose "More info → Run anyway".
  • No auto-update yet. Upgrading means downloading a new package.
  • Trace paging is limited. The panel loads 50 turns at a time.

Install

  1. Download the portable zip or the setup .exe from Releases.
  2. Extract somewhere real — not inside the zip — then run SinceArc.exe.
  3. Needs WebView2 Runtime, shipped with Windows 11 and recent Windows 10.
