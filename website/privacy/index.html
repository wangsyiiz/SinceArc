Summary

SinceArc is a desktop client for AI coding agents that run on your own computer. It has no user accounts, no analytics, no telemetry and no crash reporting. We do not collect, receive or store your personal data on any server. Everything SinceArc knows about you — sessions, messages, settings, logs — stays in a local folder on your PC and is only sent somewhere when you yourself configure a tool or service that asks for it.

This policy explains exactly what is stored, what leaves your machine and under whose control.

1. Information we collect

We collect nothing. SinceArc has no sign-up, no login, no usage statistics, no advertising identifiers, and no background reporting to the publisher. There is no server operated by us that receives data from the application.

We therefore cannot and do not sell, rent, share or otherwise disclose personal information, because we never receive any.

2. Information stored on your device

SinceArc stores its working data locally, in your Windows user profile:

LocationContents
%APPDATA%\com.sincearc.app\sincearc.dbSessions, messages, turn records, per-session state, application settings
%APPDATA%\com.sincearc.app\logs\sincearc.logTechnical log of local events (used for troubleshooting)
%APPDATA%\com.sincearc.app\*.db-wal, *.db-shmSQLite working files for the database above

This data may contain whatever you type into the application — prompts, agent replies, file paths, repository names, code snippets and any personal details you choose to include in a message. It is stored unencrypted and protected by your Windows account permissions, the same way your documents are. It never leaves your device unless you copy it out or a tool you configured (see section 3) receives it.

You can delete a single session inside the app, or remove everything at once by closing SinceArc and deleting the %APPDATA%\com.sincearc.app folder.

3. Network connections

SinceArc is offline-first. The following connections are the only ones the application itself can make:

  1. Update check (optional, user-initiated). When you click *Check for updates* in Settings, SinceArc requests a small version manifest from GitHub Releases (https://github.com/wangsyiiz/SinceArc/releases/...). The request contains no personal data beyond what any HTTP request carries (your IP address is visible to GitHub, as with any website). We do not receive or log these requests. If a newer version exists and you choose to install it, the installer is downloaded from the same GitHub Releases page. GitHub's own privacy statement governs that traffic. SinceArc never checks for updates silently in the background. If you installed SinceArc from the Microsoft Store, updates are delivered by the Microsoft Store and this GitHub request is not made.
  2. Agents you configure. SinceArc drives external agent programs (for example command-line coding agents) that you install and configure yourself. Your prompts and the files they read are handled by those programs, under their own terms and privacy policies. If such an agent talks to a cloud model provider, your content goes to that provider — not to us.
  3. MCP servers you configure. If you add Model Context Protocol servers with a remote URL, SinceArc connects to the addresses you entered. Those servers are third parties of your choosing.
  4. GitHub CLI. Repository and pull-request features use the GitHub CLI (gh) that is already installed and authenticated on your machine, with your credentials. SinceArc does not store GitHub tokens; authentication lives in the GitHub CLI's own credential store. Requests go to GitHub under your account, subject to GitHub's privacy statement.
  5. Links you click. External links open in your default browser; SinceArc does not embed a browser and does not track what you open.

Apart from these, SinceArc does not contact any server, and there is no remote configuration, remote feature flag, or A/B testing channel.

4. Diagnostics and error handling

SinceArc writes a local technical log (logs\sincearc.log) that you can inspect or share yourself. Nothing is uploaded automatically. If you choose to send us a log while reporting a problem, you do so deliberately and can review its contents first — logs may contain file paths and message text.

5. Children

SinceArc is a developer tool and is not directed at children. We do not knowingly collect information from anyone, including children under 13.

6. Your rights and choices

Because we hold no personal data about you, there is nothing for us to export, correct or erase on our side. You retain full control of the local data described in section 2: you can delete individual sessions in the app, delete the whole data folder at any time, and uninstall the application, which removes the program files. Uninstalling does not automatically delete %APPDATA%\com.sincearc.app; delete that folder if you want the data gone.

7. Security

Local data protection relies on your Windows account and disk. We recommend using a Windows account with a password and, where appropriate, BitLocker disk encryption. Since the application stores data unencrypted locally, anyone with access to your user profile can read it.

8. Changes to this policy

We may update this policy when the application's behaviour changes — for example if a future version adds an optional online feature. The effective date above always reflects the current version, and the policy is published at https://sincearc.com/privacy/.

9. Contact

Questions about this policy or about data handling in SinceArc: GitHub Issues (or the support address shown on the Microsoft Store listing)
